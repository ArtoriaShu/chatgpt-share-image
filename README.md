# ChatGPT 分享长图 · 本地版

一个用于 Chrome + Tampermonkey 的油猴脚本：单条回答一键复制为图片，也可以多选消息生成高清 PNG 长图。

当前版本：**v1.0.12**。绘图库已内置，安装后无需 API Key 或额外服务。

## 功能

- **单条回答直接复制**：点击回答底部“…”右侧的图片图标，后台生成 PNG 并复制到剪贴板。只显示短提示，不打开预览面板、不扫描历史。
- **多选对话**：通过右下角“分享为图片”读取当前对话，可以全选、只选回答或选择指定消息。
- **分享排版**：保留正文实际字体、颜色与静态布局，包括 Markdown、表格、代码配色、多栏、时间线、SVG/Canvas 及已渲染公式；可修改标题和外框深浅配色。
- **长图输出**：多选默认宽 1520 像素，按内容边界自动分图，支持下载和复制。
- **正文配图**：保留图片卡片、缩略图按钮中的正文图片，来源引用保留为紧凑文字标签，忽略站点小图标；支持跨域配图读取。
- **本地处理**：不上传对话，不调用 ChatGPT 内部对话 API，不记录聊天日志。

## 安装到 Chrome

[直接安装油猴脚本](https://raw.githubusercontent.com/ArtoriaShu/chatgpt-share-image/main/dist/chatgpt-share-image.user.js) · [下载版本](https://github.com/ArtoriaShu/chatgpt-share-image/releases/latest)

1. 安装官方 [Tampermonkey（油猴）](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)。
2. 在 `chrome://extensions/` 中进入 Tampermonkey 的详情，开启“允许用户脚本”。旧版 Chrome 按油猴提示开启开发者模式。参见 [油猴说明](https://www.tampermonkey.net/faq.php#Q209)。
3. 从 [Releases](https://github.com/ArtoriaShu/chatgpt-share-image/releases/latest) 下载 `chatgpt-share-image.user.js` 或 ZIP 安装包。
4. 油猴管理面板 → 实用工具 → 从文件导入，选择下载的文件，确认安装。也可从本仓库的 [`dist/`](dist/) 获取安装文件。
5. 刷新 ChatGPT 对话页面。

如果导入界面不接受 JS 文件：用文本编辑器复制脚本全部内容，油猴 → 添加新脚本，替换默认内容，保存。

### 从旧版本更新

重新安装最新 `.user.js` 或从油猴导入 ZIP，选择更新，再刷新 ChatGPT。v1.0.8 新增 `GM_xmlhttpRequest` 和 `@connect *`，用于读取不同网站的正文图片；油猴可能要求确认图片域名权限。跨域补充请求只访问当前选中内容中的图片地址，设置 `anonymous: true`，不发送对话文字或站点 Cookie。

## 使用

**分享单条回答**：点击回答底部的图片图标。看到“图片已复制”后，可直接粘贴给朋友。沿用多选面板最近设置的外框配色，正文保留网页配色。浏览器拒绝复制时，小提示提供“重试复制”和“保存 PNG”。

**分享多条消息**：点击右下角“分享为图片”。脚本会自动滚动读取当前对话，并恢复原滚动位置。读取完成后选择消息、标题、配色和图片长度，点击“生成图片”。生成后每张图片可分别复制或保存。

## 范围与限制

- 仅识别当前页面已显示或滚动后加载的当前对话分支。完整旧历史仍依赖网页自行加载。
- 外层使用分享卡片，正文保留读取时的网页样式并适配输出宽度，不保证逐像素一致。仅导出已加载的静态状态；跨域 iframe、视频、WebGL、封闭 Shadow DOM、附件文件及折叠/未加载内容不保证可导出，不承诺覆盖 ChatGPT 的全部未来组件。
- 为导出图片，优先复用已加载且允许读取的图像；普通读取失败后，跨域图片使用油猴匿名请求，同源图片可使用现有站点会话。过期地址、反盗链或必须登录外部网站的配图仍可能失败，此时以提示框代替并显示数量。来源引用按小号文字标签显示，站点小图标不作为正文图片读取，不计入配图失败数量。
- 单条回答复制为一张完整图片。很长的回答会适当降低分辨率，最高 32760 像素高；超过 32000 CSS 像素的极长回答，请使用多选入口分图保存。
- 多选模式默认每张最长约 9600 像素；“较长图片”最长约 24000 像素。单批最多 40 张，跳过的消息会标明省略数量。
- 整段读取有 90 秒和 600 步上限。停止或未确认完整时会明确提示。回答结束后再使用；页面新增消息或切换对话后，多选模式需要重新读取。
- ChatGPT 页面结构改变后可能需要更新脚本。

## 开发与测试

需要 Node.js 20 或更高版本。

```sh
npm install
npx playwright install chromium
npm run build
npm test
```

如果使用已有 Chromium，可通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指定浏览器路径。

- `src/`：可读源码及油猴元数据。
- `vendor/`：内置 html2canvas-pro 2.5.0 及其 MIT 授权。
- `dist/`：可直接安装的脚本及 ZIP。
- `tests/browser.mjs`：消息识别、正反向滚动、虚拟列表、单条复制、多选分图、主题、下载、取消、切换对话保护和重复注入。
- `tests/direct-copy.mjs`：长回答完整复制、面板隐藏、浏览器拒绝后的重试。
- `tests/images.mjs`：来源图标过滤、图片卡片保留、跨域读取回退、实际 PNG 像素、失效配图计数。测试中的油猴请求接口用桩函数连接独立图片服务。
- `tests/layouts.mjs`：双栏卡片、标签颜色、类名加粗、SVG 正文图标与紧凑来源标签，检查布局和导出 PNG 中的图标像素。
- `tests/clipping.mjs`：浮动辅助元素导致长回答末段裁切的回归验证，检查末段位置和 PNG 中的实际可见像素。
- `tests/appearance.mjs`：三栏比例、CSS 时间线、定位示意图、代码配色、表格、宽 SVG、Canvas、背景图片及来源标签尺寸。

v1.0.7 已通过上述自动化测试，并在实际已登录的 Chrome 对话中验证单击复制成功且不打开面板。

## v1.0.12 更新

修复正文重新换行后末尾被裁掉的问题：普通正文不再因为包含浮动辅助元素而保留网页旧高度；定位内容允许随文字增长；图片与字体就绪后重新检查固定布局盒的垂直溢出。新增较宽网页导出至较窄长图的末段边界及实际 PNG 像素验证。

## v1.0.11 更新

从局部卡片适配扩展为通用正文样式快照：保留静态多栏、时间线生成装饰、定位图、代码配色、表格、SVG/Canvas 和背景图片；对布局宽度做适配。正文沿用网页配色，外框可选深浅色。来源标签恢复为紧凑文字胶囊，最高 180px 宽、20px 高，避免网站图标放大。权限不变，交互和受限嵌入内容仍有上述限制。

## v1.0.10 更新

保留正文 HTML 卡片的双栏布局、边框、颜色、标签与字重，将 SVG 正文图标转换为可导出的图片。网格列按比例适配长图宽度，继续过滤来源引用标签。权限不变；已添加模拟卡片的布局与实际 PNG 像素验证，具体 ChatGPT 页面效果由用户验证。交互组件、复杂定位和动画仍不保证逐像素还原。

## v1.0.9 更新

来源引用标签整块过滤：小图标、来源文字及 `+1` 等数量均不进入导出图片或消息摘要；补充识别只有弹出标记与图标的来源标签。保留正文配图、普通链接和相邻段落。权限与 v1.0.8 相同。自动化验证覆盖标签过滤及正文配图保留。

## v1.0.8 更新

修复图片卡片因外层按钮或 `thumbnail` 标记被删除的问题；保留可见正文图片，去掉来源引用图标。新增跨域图片读取与同源会话读取回退。单条按钮仍直接复制，不弹出面板。此版包含模拟页面与独立跨域图片服务的自动化验证，尚未在实际油猴会话中验证新权限。
